а) def foo(a):
    for i in range(len(a), 0, -1):
        for j in range(1, i):
            if a[j-1] > a[j]:
                a[j-1], a[j] = a[j], a[j-1]
    return a

внешний цикл выполняется n раз (i = n, n−1, ... , 1) внутренний цикл для каждого i выполняется i − 1 раз
общее число итераций внутреннего цикла (n - 1) + (n - 2) + ... + 1= n(n-1)/2
каждая итерация внутреннего цикла выполняется за O(1)
ответ: T(n) = O(n^2)
это вариант пузырьковой сортировки, работающий сверху вниз - после каждого прохода наибольший элемент оказывается в конце.

б) def Foo(arr):
    for i in range(1, len(arr)):
        temp = arr[i]
        j = i-1
        while (j >= 0 and temp < arr[j]):
            arr[j+1] = arr[j]
            j -= 1
        arr[j+1] = temp

Это классическая сортировка вставками (insertion sort). Внешний цикл - n−1 итераций. Внутренний while в худшем случае (обратно отсортированный массив) выполняется i раз.
Общее число операций в худшем случае:
∑^i=1, n−1 i= n(n−1)/2=O(n^2)

Средний случай: O(n²) - при случайном порядке элементов.

В лучшем случае (уже отсортированный массив) - O(n).

ответ (худший случай): T(n) = O(n²).

Input: [0,1,1,1,1,1,1,4,5], 1
Output: 1

def binary_search_first(arr, target):
        left, right = 0, len(arr) - 1
    result = -1

    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == target:
            result = mid      
            right = mid - 1      
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1

    return result

print(binary_search_first([0, 1, 1, 1, 1, 1, 1, 4, 5], 1))  
print(binary_search_first([0, 1, 1, 1, 1, 1, 1, 4, 5], 4))  
print(binary_search_first([0, 1, 1, 1, 1, 1, 1, 4, 5], 9)) 

Output:
1
7
-1 

Ключевая идея: при нахождении совпадения не останавливаемся, а продолжаем поиск в левой половине, чтобы найти самое первое вхождение.

Оценка вычислительной сложности
На каждом шаге область поиска уменьшается вдвое: n -> n/2 -> n/4 → ... -> 1.

Количество шагов: log₂n

Все операции внутри цикла — O(1)

Итоговая сложность:

По времени: O(log n)

По памяти: O(1) 
Это не хуже обычного бинарного поиска — модификация лишь добавляет постоянное число операций на каждой итерации, не меняя асимптотику.
